# Casazium

**Developer infrastructure for indie software vendors — self-hosted or hosted.**

Casazium is an indie software studio building practical, well-engineered tools without hype.

## What we build

- **[License Server](https://docs.casazium.com/docs/license-server/intro)** — Simple licensing for indie apps and SaaS. Available self-hosted or as a hosted service; the hosted beta is open.
- **[Library Server](https://bibliophilicbob.us/)** — Book cataloguing for personal and shared libraries, covering print, ebooks, and audiobooks.
- **Storage Server** — Content-addressed object storage with verifiable integrity, currently in early development.
